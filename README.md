Project Description

Built a full-featured Hospital Management System using Angular (frontend) and Spring Boot (backend). Developed responsive and interactive UI components for core modules such as Patient Registration, Doctor Management, Appointments, Prescriptions, Diagnostics, Billing, and Pharmacy.
On the backend, designed and implemented RESTful APIs, business logic, authentication, and database operations. Ensured smooth integration between the Angular frontend and Spring Boot backend for real-time data flow. The system follows structured architecture and provides reliable performance for enterprise-level use.

Tools & Technologies:
Angular, TypeScript, Bootstrap, Spring Boot, Java, MySQL, REST API, VS Code, Git, GitHub
